# Wang Gaoyang (Kenny) — Resume Website

My resume built two ways: a static HTML page and an interactive Streamlit app.

## Contents

| Path | What |
|---|---|
| `index.html` | Static one-page resume. Open it in any browser. |
| `streamlit_app/Kenny_Resume_App.py` | Interactive resume app built with Streamlit |

## Run the Streamlit app

```bash
pip install streamlit
cd streamlit_app
streamlit run Kenny_Resume_App.py
```
